CalFresh Interactive Student Eligibility Guide — Mobile Prototype

Open index.html in Edge, Chrome, Safari, or Firefox.

The QR code included in this package currently points to:
https://example.org/calfresh-student-guide

Before real use, publish index.html to an approved public web location and regenerate the QR code using that final URL.

This prototype:
- Uses the student exemption concepts from CF 6177.
- Follows the current Student Eligibility Decision Tree sequence.
- Searches the uploaded approved LPIE list (10,575 records).
- Does not determine eligibility or submit an application.
- Stores and transmits no answers.

Before production use, CDSS should validate policy logic, wording, accessibility, security/privacy, LPIE matching, and update governance.
